# Economy Bounties

A data-driven bounty and commission framework for Minecraft, designed as an addon for [Economy](https://github.com/UpperMoon0/Economy).

The bounty engine owns gameplay concepts such as groups, tiers, weighted deterministic generation, progression eligibility, objectives, rotations, cooldowns, completion tracking, and rewards. Economy remains responsible for accounts, currency, transactions, and market infrastructure.

> Status: initial implementation in progress.
