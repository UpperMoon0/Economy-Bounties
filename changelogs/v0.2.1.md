# Economy Bounties 0.2.1

## Visual Orders screen
- Replace text-only order rows with real Minecraft inventory item icons, requested quantity, reward, rarity and clear selection feedback. Both vanilla and modded registered items use their own sprite; invalid datapack item IDs show the barrier icon.
- Replace the previous one-item VirtualList detail pane with a reactive retained detail host. Its details now use an **independently scrollable OpenUI ScrollView** and the actions remain **pinned outside the scroll area**.
- Show actual server-reported inventory progress with a graphical bar, clear item requirement, prominent Economy reward, order timer, rarity and scope.
- Improve 40/60 list/details split, center the larger responsive screen, and stack both panes on narrow clients while preserving selectable keyboard-friendly rows.
- Keep the selected order slot stable across server refreshes, but refresh its content when the offer or inventory changes.

## Compatibility
- Economy Bounties **0.2.1** for the UI update. Requires Economy **0.0.23+** and OpenUI MC **0.0.16+**.
- Existing server-side automatic-order gameplay, payout and datapack compatibility are unchanged.
