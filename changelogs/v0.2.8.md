# Economy Bounties 0.2.8 — Visual Job Composer

- Replace the fixed-height Create objective `VirtualList` with content-sized cards in one scrollable form. One objective no longer reserves an empty 132px viewport; multiple objectives grow naturally, with the outer form responsible for scrolling.
- Use a player-facing **Job details** composer: native Name Tag and Paper sprites, compact Economy reward and clock/lifetime cards, readable sections, and a job icon selector with native vanilla item previews. **Held** copies the real main-hand item ID, including modded items; an optional custom ID editor remains available.
- Objective cards use native item/tool icons for deliveries, mining, crafting, hunting, fluids and dimension visits. Quick-pick dropdowns show matching Minecraft item icons and predefined valid targets. Held-item selection and optional custom target IDs support modded content.
- Preview the actual job as a graphical card: icon/title, Public/Restricted badges, reward/time tiles, icons and readable objectives. Remove verbose technical explanation paragraphs.
- Fix clipped submission button: compact **Check** and **Post** actions stay in the pinned right footer, with concise hover descriptions. Client rejects missing titles, non-positive rewards, invalid lifetimes and missing objective targets/quantities before sending the server request.
- Turn unused sidebar space into a bounded live Board overview (available offers, accepted jobs, player posts) sourced from the server snapshot. Navigation remains independently scrollable and without numeric prefixes.
- Improve My Jobs and Player Jobs visual cards with action/type icons, status badges, and concise tooltip-backed descriptions.
- Preserve server-authoritative Economy escrow, order generation, payout checks and audience permissions.

Requires Economy 0.0.23+ and OpenUI 0.0.16+. Same UI implementation is shared across Minecraft client targets.
