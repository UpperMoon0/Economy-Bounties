# Economy Bounties 0.2.4 — Bounty Board navigation and browser redesign

- Replace the large top tab switcher with a scrollable, selectable **Economy Market-style left sidebar**: Orders, Contracts, Posted, Create.
- Use a compact header and toolbar to reclaim vertical space.
- Orders: scrollable real-item **grid (default)** or dense list, text search, Personal/Global scope, Normal/Special type, Ready/Available/Taken/Restocking status, sort by readiness/reward/expiry/item, and a Ready-only quick toggle. Specials are types, never separate scopes.
- Orders details: native item icon, scope/rarity badges, inventory progress, reward and countdown, with independently scrolling details and pinned Deliver, Accept, Discard and View Contracts actions.
- Contracts: remove all manual Roll controls; searchable, sortable, filterable card grid/list; selectable contracts with full objectives and progress, scrollable detail body and pinned available actions.
- Posted: same browser/detail pattern, search, status, sorting and **Mine** filter. Server snapshots now include trusted `ownedByPlayer` and the configured item icon, with a backward-compatible Java record constructor.
- Create: two-column responsive editor and live preview, scrollable objective editor with all six built-in types, advanced audience/progression controls, local Preview validation, and fixed Back/Create & fund footer.
- Fix multi-line virtual list clipping by allocating explicit card heights and using `VirtualGrid`/`VirtualList` for browsers, `ScrollView` only for long details/editors, not one-row virtualized expanded cards.
- Retain server-enforced no-player-Roll policy, configured random system order restocks, inventory delivery, idempotent payments and existing Posted funding rules.

Requires Economy 0.0.23+ and OpenUI 0.0.16+. All Minecraft client variants share the same screen layout.
