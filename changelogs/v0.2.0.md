# Economy Bounties 0.2.0

- Add a Hay Day-style, automatically populated **Orders** tab to the Bounty Board OpenUI screen.
- Introduce data-pack-driven item-input pools, independent weighted reward tiers, rarity labels, delivery quantities, level requirements and optional time windows.
- Ship six personal order slots, shared first-come town dispatches, daily specials and seasonal event orders.
- Support no deadline, offer-expiry and accepted-time deadline policies. Restock a slot only after an accepted contract completes/cancels/expires and its cooldown passes.
- Persist order slots, generated offer IDs, scheduled restocks and claim locks. Recover interrupted grants without issuing duplicate rewards or giving an order to two players.
- Add read-only Economy Market quote integration with bounded 0.5–2x reference values, board-level reward limits and fixed server-authoritative payout amounts.
- Make the UI inventory-aware: view requested item quantities, owned counts, reward badges, deadline/cooldown indicators, scope filters, and **Deliver now** to accept, consume and claim a fully stocked order in one action.
- Retain legacy manually rolled **Contracts**, manually funded **Posted** bounties, escrow recovery, and the same protected item/fluid delivery path.
- Bump stable mod version to **0.2.0**, requiring **Economy 0.0.23+** and **OpenUI MC 0.0.16+**.

All config and persistence formats are documented at `docs/automatic-orders.md`. No production world or server changes are part of this release candidate.
