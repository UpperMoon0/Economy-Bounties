# Economy Bounties 0.2.2

## System order generation policy

- Remove player-facing **Roll** and **Pools** controls from Contracts; use the recovered vertical space to display accepted contracts.
- Deny legacy `ROLL` requests at the server packet entry point. Old or modified clients cannot generate new system offers.
- Remove the direct Minecraft runtime manual-roll entry point and omit rollable pool IDs from server snapshots; retain the internal bounty engine definitions for datapack compatibility/tests.
- Keep scheduled Personal/Global automatic Orders, player-funded Posted bounties, and existing claim/delivery flows intact.
- Add a regression test enforcing the protocol policy and preserving other client actions.

Requires Economy 0.0.23+ and OpenUI 0.0.16+.
