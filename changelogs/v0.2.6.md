# Economy Bounties 0.2.6 — Dense grid and keyboard-friendly navigation

- Remove redundant Close button: Escape uses the normal OpenUI dismiss/close flow, and the configured inventory key (E by default) closes the board unless a text field is focused or a blocking overlay owns the key.
- Eliminate the empty notification row between the active title/Refresh and search toolbar; show notices inline in the header.
- Make Orders' Grid/List choice rebuild the actual browser/detail geometry: Grid receives 67% of available width and guarantees multiple compact item tiles at usable GUI widths; List retains a 55% browser split.
- Render dense Grid-only tiles with item icon, quantity, payout, rarity, scope, progress and timer. Expanded content and actions remain in the detail pane.
- Replace fixed detail scroll heights with flexing OpenUI ScrollViews. Order, Contract, Posted and Create footers are now genuinely bottom-pinned and right-aligned without extra blank space below.
- Preserve all existing server-authoritative actions, automatic orders and filters.

Requires Economy 0.0.23+ and OpenUI 0.0.16+.
