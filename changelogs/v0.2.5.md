# Economy Bounties 0.2.5 — Fill the Board and Remove Duplicate Headings

## Root-cause fixes
- OpenUI `VStack` uses the tab switcher's **preferred height** during layout. The selected tab's virtualized browser reports approximately one card row, so the previous screen left most of its allocated height unused despite a full-height outer card.
- Assign an explicit height to the main `SignalSwitcher`, each Orders/Contracts/Posted browser row, and the Create split pane. Reserve exactly the header and toolbar heights; the browser and independent detail scrollers now expand to fill the remaining window height.
- Replace duplicate `Bounty Board` headings with a single compact sidebar brand (`BOUNTIES`) and a reactive **Orders / Contracts / Posted bounties / Create bounty** header.
- Remove the redundant Orders refresh action (the one in the header is retained). Rebalance the search, scope, type, status, sort, Ready-only, and Grid/List controls across compact toolbars, with wider dropdowns to prevent label truncation.
- Keep the sticky action footers and all server-authoritative bounty actions unchanged.
